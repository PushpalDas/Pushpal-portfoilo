## If asked

- **"What happens with real data?"** — The same adapters, pointed at read-only exports; every export reconciles to its source total by test before a screen shows it, as Patents and Ops do today.
- **"Why rules and not a model?"** — A rule's attribution is a weight a controller can disagree with; the first month of a pilot is her learning which rules to trust. A model comes later, at the edge, held to the same contract: cite rows or be dropped.
- **"What would make you stop?"** — Case study §09: any agent action, any finding without evidence, any write to Ops or Patents, any derivable individual pay, precision under 0.90 on a rule in a real month, the controller absent two weeks.

## Reset

Every state above is a link; nothing persists between visits. Session decisions (approvals, accepted matches, reclass proposals) live in the tab and are gone on reload.
