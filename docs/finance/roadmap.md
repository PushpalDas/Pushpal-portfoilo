# Roadmap — Now / Next / Later

**Audience:** the founder and the finance lead. **Purpose:** what exists, what comes next and what is deliberately later, each tied to a capability and to the measure that would move it. Dates are not promised; gates are. Every figure is illustrative and from the synthetic ledger unless marked *pilot*.

## Next — PLANNED, the read-only pilot

| Step | Capability | Measure | Gate |
|---|---|---|---|
| 1 | Nightly read-only exports (accounting system, card issuer, processor, payroll provider in aggregate) replayed through the same adapters | Every export reconciles to its source total by test, as Patents and Ops do today | All four totals to the cent; any write path found → stop |
| 2 | Finance lead labels one real month; the harness scores each rule | Precision and recall per rule with n | ≥ 0.90 precision per rule or the rule retires to advisory |
| 3 | The Founders-office associate works the queue for four weeks; every accept / dismiss is an audit event | Acceptance per rule with n (today n = 0) | Finance lead opens the queue weekly; two missed weeks end the pilot |
| 4 | Close run in parallel for two months | Readiness at BD+5, tasks evidenced by the rows | The checklist agrees with the finance lead's own list on every task |
| 5 | Business case's measured column filled | Hours per close, measured before and during | The modelled column is retired |

## Later — deliberately not yet

| Capability | Why later | What would bring it forward |
|---|---|---|
| L2 auto-execute for exact bank matches under $500 | Trust is earned on human decisions, not on a synthetic set | 200 decisions at precision ≥ 0.98 (trust note §4) |
| A model at the edge (explaining a reclass, drafting a vendor query) | A rule's attribution is arguable at the weight; a model's is not, and the first month is the finance lead learning which rules to trust | Rules earned; the model never in the critical path; every model output cites rows or is dropped |
| A second entity's statutory books | The accounting system is the ledger of record for statutory work; this is a review layer | Never as the ledger of record; as a reader of it |
| Multi-currency beyond USD / INR with live rates | The seed fixes a monthly rate; a pilot reads the accounting system's | The pilot's export carries the rate |
| Vendor portal and self-service bank changes | The riskiest flow in the ledger; a portal makes the fraud path shorter | Only with call-back enforced by the flow, not by a person remembering |

## Kill gates (from the case study §09, agreed before build)

Any agent action → stop the same day · a finding shown without evidence → stop that agent · any write to Ops or Patents → stop the adapters · individual pay derivable → stop the payroll feed · precision under 0.90 per rule on a real month → advisory · controller absent two weeks → end the pilot.
