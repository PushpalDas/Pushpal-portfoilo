What this demo is

A working recreation of the drafting clock inside the patent programme described in the case study. Nine stages per matter, every date a cited message. The mailbox, calendars, group chats and workbooks are simulated; the stage model, the T0 targets, the selection rules, the citation rule and the review queues are the real ones.

The four rules it makes visible

1. A stage has a date only when a message, an event or a chat line says so. The system reads get only and writes nothing back.

2. The days between stages are measured against targets fixed before the first matter was read, and coloured by how far over — not by whose fault.

more

3. A reason for delay must cite the messages it rests on. A reason with no citation is dropped before anyone sees it; the card says so when that leaves it empty.

4. A model may suggest a match and write a status; it never picks a date. Winners are chosen by rule, and a person can reject, select or set any of them — each an attributable decision.

Every matter, reference name, firm, person, date, subject line and message on this page is invented for the demo. No unpublished subject matter, inventor, attorney, firm name, matter number or statutory date from the real programme appears here. The stage model, the targets and the counting rules are the real ones, so the grid can be checked rather than taken on trust.
