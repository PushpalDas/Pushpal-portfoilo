# CLAIMS AUDIT — evidence classes and headline calibration (P7)

Classes: **A** public & verifiable (live spec pages, arXiv/DOI/patents, papers, anything
clickable-demonstrable in a linked demo, video) · **B** real but protected (page says
real-but-masked/relative) · **C** illustrative placeholder (page's own note declares invented).

Rule applied: headline positions (card outcome, Positioning/deck, Result summary, title,
pull line) rest only on A/B. C figures demoted to worked-example position in-body; §08 metrics
tables stay, framed by the unified Data note. Verbs per the ladder (shipped/delivered/proved
need A/B; built/designed/demonstrated-in-the-harness/measured-in-the-eval otherwise).

Format per project: A-assets · headline verdicts · before→after for every calibrated claim.
